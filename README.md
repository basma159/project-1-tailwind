🚀 DigitalPro - Digital Marketing Landing Page
📖 Description

A modern and responsive landing page for a digital marketing agency. The project features a clean interface, responsive layouts, service cards, statistics, team members, and a contact section, built using Tailwind CSS.

✨ Features
Responsive design.
Fixed navigation bar.
Hero section with Call-to-Action buttons.
Services section with interactive cards.
Statistics section.
Team members section with hover overlay effects.
Contact form.
Contact information section.
Modern footer with social media links.
Smooth hover and transition effects.

Tailwind CSS
Font Awesome
